# Implementation plan

## Open tasks

### RL-029 — [OPS] Standardize the local development lifecycle

- Dependency: None.
- Why: `npm start` runs bare `vite` with `strictPort`. A RigLab dev server left running by an earlier `npm start` (in a forgotten terminal tab, or from a worktree) keeps port 5180, so the next `npm start` dies with `Error: Port 5180 is already in use`. On 2026-10-13 a 13-hour-old `npm start` on another terminal did exactly that. The owner wants RigLab to follow the teardown, reset, build and start lifecycle that SharkTank (`scripts/local.mjs`) and WizardGang (`scripts/dev.mjs`) already use, so that error never happens to RigLab's own servers.
- Scope: `npm run dev` runs `node scripts/dev.mjs`, and `npm start` still runs `npm run dev`. The launcher runs these steps in order and names each one as it starts. Teardown: stop the server that this checkout's last run recorded in `tmp/dev/server.json`, when that process is still this checkout's Vite. Then stop every other listener on the port that is a Vite started from this repository, meaning its command runs `node_modules/.bin/vite` or `node_modules/vite/bin/vite.js` under this checkout or one of its `git worktree list` worktrees. Send `SIGTERM`, then `SIGKILL` if it is still running after a bounded wait, and confirm the port is free. Any other listener is refused, with its PID and command, how to inspect it, and the `RIGLAB_PORT` override. The launcher never signals a process it cannot prove is RigLab's. Reset: remove `dist/`, `node_modules/.vite/` and `tmp/dev/`, and refuse any path outside the checkout. Install: run `npm ci` when `node_modules/` is missing or `package-lock.json` has changed since the last install the launcher recorded. Build: `vite build` against the same library the server will read, so a broken library or import fails before anything is served. Start: Vite on `RIGLAB_PORT`, else 5180, with `--strictPort`, in its own process group, recorded in `tmp/dev/server.json`. Readiness: wait a bounded time for HTTP success at `http://localhost:<port>/`, print the URL, and open the browser unless `--no-open` or `RIGLAB_NO_OPEN=1` is set. Stop: Ctrl-C, `SIGTERM` or `SIGHUP` (a closed terminal) stops Vite and removes the record, and Vite exiting on its own ends the launcher with Vite's code. Keep the pure rules (port parsing, ownership matching, reset targets, install decision) in `scripts/dev-lifecycle.mjs` with injectable process and file access. The repository contract requires `dev` to be `node scripts/dev.mjs`. `tmp/` is ignored. Update the README's run section and command map.
- Non-goals: Stopping a process that is not a RigLab Vite, Windows support beyond a clear refusal, changing the library plugin, `vite preview` or `npm run check`, a background or daemon mode, and changing `vite.config.ts`'s default port.
- Acceptance: Contract tests cover the following. A port must be a whole number from 1 to 65535. Ownership matches this checkout's and a worktree's Vite. It rejects Vite under another repository, a sibling path that only shares the prefix (`RigLab-old/`), a non-Vite node process in the checkout, and an unreadable process. Every reset target stays inside the checkout. Install runs only for a missing `node_modules/` or a changed lockfile. The repository contract refuses a `dev` script other than `node scripts/dev.mjs`. Live, on a worktree with a spare `RIGLAB_PORT`, five things hold. A RigLab `npm start` left running on the port is torn down, and the new run serves the editor and `/wardrobe/`. A second run while one is serving replaces it. A foreign listener on the port is refused with its PID and is still running afterwards. `SIGINT`, `SIGTERM` and `SIGHUP` each leave no listener and no `tmp/dev/server.json`. `--no-open` opens no browser. `npm run check` passes.
- Validation: Pinned `npm ci`, the focused contract tests, `npm run check`, `npm run audit:dependencies`, `check:patch`, `git diff --check`, the live lifecycle runs on a worktree, and exact-head CI.
- Authorities: `package.json`, `vite.config.ts`, `scripts/repository-contract.mjs`, `tests/contracts/repository-contract.test.mjs`, `.gitignore`, `README.md`, SharkTank's `scripts/local.mjs` and `scripts/local-process-ownership.mjs`, WizardGang's `scripts/dev.mjs`, and owner direction on 2026-10-13.
